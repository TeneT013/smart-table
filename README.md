# sp6-2_smart-table_starter
https://github.com/TeneT013/smart-table

Интерактивный компонент таблицы данных на чистом JavaScript (Vanilla JS), собранный с помощью **Vite**. Проект реализован в рамках обучения веб-разработке и демонстрирует архитектуру модульного фронтенда: фильтрацию, сортировку, пагинацию и гибкий полнотекстовый поиск.

---

## 🚀 Функциональность

* **Динамическая таблица:** Рендеринг данных из API.
* **Полнотекстовый поиск:** Глобальный поиск по нескольким полям через кастомные правила сравнения.
* **Многокритериальная фильтрация:** Поиск по колонкам, сброс отдельного поля по кнопке `clear`, выбор продавца и фильтрация диапазона чисел (`from`/`to`).
* **Сортировка:** Переключение режимов (по возрастанию / по убыванию / сброс) с использованием карты состояний (`sort.js`).
* **Пагинация:** Настройка количества элементов на странице, динамическое переключение страниц.

---

## 🛠 Технологический стек

* **Сборщик:** Vite
* **Язык:** JavaScript (ES6+ Modules)
* **Стили:** CSS3 (кастомные шрифты YS Text / YS Display)
* **Система контроля версий:** Git + GitHub Actions (CI/CD)
